# AI Translations

Коллекция переведённых материалов по проектированию AI-систем, AI-агентам и архитектурным паттернам.

## Что здесь

- **AI Паттерны** — переводы [agent-patterns](https://agent-patterns.readthedocs.io/) и других каталогов паттернов
- **Курсы** — структурированные учебные траектории из переведённых материалов
- **Статьи** — самостоятельные переводы ключевых работ

## Как устроено

Каждая статья доступна на двух языках — переключайтесь кнопкой в шапке сайта.

Переводы делаются вручную, с упором на точность и читаемость, а не дословный подстрочник.
